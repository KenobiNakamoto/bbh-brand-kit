# Guidelines

The canonical BBH brand document lives here: [`brand-guidelines.docx`](./brand-guidelines.docx).

If anything in this repo disagrees with `brand-guidelines.docx`, the guidelines win. The design tokens, READMEs, and AI pack are compact derivatives of the guidelines — they exist to make the brand consumable by code and by LLMs. They do not replace the source document.

## What's inside

- The founding story and the Solo Bitcoin rule.
- Voice, tone, and bilingual Spanish/English rules.
- Logo lockups, clear space, and forbidden uses.
- Colour palette with print / screen / specimen references.
- Typography specimens and pairings.
- Photography style and treatment.
- Editorial motifs (masthead, rules, Venn diagram, pull quotes).
- Templates and deliverable formats (posters, social, deck).

## Reading order

If you are new to BBH and you need to produce something quickly, read in this order:

1. `README.md` (root) — the one-page orientation.
2. `guidelines/brand-guidelines.docx` — the full source of truth.
3. `USAGE.md` — practical cheat sheets for common deliverables.
4. `ai-pack/AI_README.md` — only if you are handing the brand to an LLM.

For questions not answered by any of the above: `barcelona_btc_hub@proton.me`.
