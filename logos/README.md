# Logos

Official BBH marks. Use only unmodified versions from this directory.

## Variants

| Variant | File | Use on |
|---------|------|--------|
| Round, black | `round/bbh-round-black.svg` (+ `.png`) | Parchment / light backgrounds |
| Round, white | `round/bbh-round-white.svg` (+ `.png`) | Midnight Ink / dark backgrounds |
| Square, black | `square/bbh-square-black.svg` (+ `.png`) | Parchment, small formats |
| Square, white | `square/bbh-square-white.svg` (+ `.png`) | Midnight Ink, small formats |
| Mark only, black | `wordmark/bbh-mark-black.svg` | Favicons, tiny badges |
| Mark only, white | `wordmark/bbh-mark-white.svg` | Footer stamps on dark |
| Wordmark (text), black | `wordmark/bbh-wordmark-black.svg` | Headers where the mark is elsewhere |
| Wordmark (text), white | `wordmark/bbh-wordmark-white.svg` | Dark headers |

## Clear space

Maintain at least **one cap-height of the "B"** (the height of the uppercase letter) in empty margin around any logo — on every side. The clear space is not decorative, it's structural.

## Minimum sizes

- Round / square logos: **32px** digital, **12mm** print.
- Wordmark only: **24px** digital, **8mm** print.
- Mark only: **16px** digital, **5mm** print.

Below these sizes, the logo may not render legibly and should be omitted in favour of the text "BBH".

## Do not

- Recolour. Use black on Parchment or white on Ink only.
- Rotate, skew, shear, or add perspective.
- Add drop shadows, glows, outlines, or embosses.
- Place the logo on a textured photo background without a solid-colour shape behind it.
- Place the orange variant on an orange background (yes, someone has tried).
- Crop into the mark (e.g., to use only half of it as decoration).

## Formats

- **SVG** — use for web, app, and any digital surface. Scales perfectly.
- **PNG** — fallback for legacy tools (slides that don't accept SVG, some email clients). PNGs are rendered at 8× the nominal size (e.g. 8000px wide for a 1000px display size) for print-quality reuse.
- **AI source files** are in the project archive, not in this repo. Contact `barcelona_btc_hub@proton.me` for vector originals.
